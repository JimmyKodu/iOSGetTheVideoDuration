# iOSGetTheVideoDuration

iOS视频时长获取工具 - 支持MOV格式的5种方案自动切换

## 功能特点

- 📱 完美支持iOS设备转换的MOV格式视频
- 🔄 5种不同的获取时长方案，自动切换
- ⏱️ 智能超时处理（每个方案5秒超时）
- 🎨 实时渲染处理过程到页面
- 📊 显示详细的视频信息

## 5种获取时长的方案

1. **方案1: loadedmetadata事件** - 当视频元数据加载完成时触发
2. **方案2: canplay事件** - 当浏览器可以开始播放视频时触发
3. **方案3: loadeddata事件** - 当当前帧数据加载完成时触发
4. **方案4: durationchange事件** - 当时长属性改变时触发
5. **方案5: 轮询检测** - 定期检查视频时长属性（100ms间隔）

## 使用方法

1. 打开 `index.html` 文件
2. 点击或拖拽视频文件到上传区域
3. 系统会自动尝试5种方案获取视频时长
4. 页面实时显示每种方案的状态（尝试中/成功/失败）
5. 成功后显示视频时长和使用的方案

## 技术实现

- 纯HTML + JavaScript实现，无需任何依赖
- 使用HTML5 Video API
- 使用Promise实现异步方案切换
- 响应式设计，支持移动端
- 优雅的UI动画和状态展示

## 浏览器兼容性

- iOS Safari 10+
- Chrome 50+
- Firefox 50+
- Edge 14+

## 为什么需要多种方案？

iOS设备在处理视频时可能会将视频转换为MOV格式，不同的iOS版本和浏览器版本对视频元数据的加载时机不同。通过提供5种不同的方案并自动切换，可以最大程度保证在各种环境下都能成功获取视频时长。

## 超时机制

每种方案都设置了5秒的超时时间。如果一个方案在5秒内无法获取到视频时长，系统会自动切换到下一个方案。这样可以避免某个方案卡住导致整个流程无法继续。
